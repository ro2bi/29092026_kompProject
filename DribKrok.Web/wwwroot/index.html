Що повторити далі

    Правила, які завжди під рукою

    Не відповідь. Опора для думки.
    01

    Однакові частинки

    Перед додаванням зроби знаменники однаковими. Знайди число, яке ділиться на кожен із них.

    02

    Зміни обидва числа

    Множ чисельник і знаменник на те саме ненульове число. Значення дробу залишиться незмінним.

    03

    Додавай кількість

    Коли знаменники однакові, додай чисельники. Знаменник показує розмір частинки — залиш його.

    Твої думки — під твоїм контролем

    Без імен, акаунтів та оцінок. Сесія зберігається лише в оперативній пам’яті сервера й видаляється після 30 хвилин бездіяльності. Не вводь особисті дані. Для демо використовуй вигадані приклади.

    Що робить ШІ та що передається назовні?

    Локальна модель Naive Bayes розпізнає стратегію за поясненням і працює без інтернету. Якщо API налаштовано й ти дозволив його використання, до OpenAI передається лише текст поля «Як ти міркуєш?» та інструкція класифікатора. Числова відповідь і сесія не передаються. Текст відповіді моделі не показується: програма приймає лише одну з п’яти категорій і обирає перевірене навідне запитання. Якщо API недоступний, працює локальна модель.

    Запити API використовують store=false. Це не гарантує відсутності технічних журналів у провайдера. Кнопка стирання видаляє локальну сесію, але не дані, вже передані провайдеру. Автоматичного розпізнавання персональних даних немає.
