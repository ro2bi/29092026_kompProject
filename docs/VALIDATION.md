# Перевірки прототипу

Дата локальної перевірки: 29 вересня 2026 року. Середовище: Windows, .NET SDK 9.0.305, цільова платформа .NET 8.

## Автоматичні перевірки

`DribKrok.Tests` виконує 31 перевірку навчального маршруту, арифметики, помилкових форматів, захисту від готових відповідей та клієнта API. Арифметичний блок охоплює 726 згенерованих прикладів із двома еквівалентними та однією неправильною відповіддю на кожен.

Локальний класифікатор: 50 синтетичних навчальних фраз, 15 окремих синтетичних тестових фраз, результат **15/15**. Тестові речення не включено в навчальний масив. Це мала перевірка регресій, написана автором прототипу, а не незалежна статистична оцінка чи дослідження реальних учнів. Не інтерпретуйте результат як «точність 100% у реальному використанні».

API тестується підставним HTTP-обробником: відсутність викликів без згоди, `store:false`, сувора схема, допустима категорія, недопустимий вивід, помилка 429, пошкоджений JSON. Живий запит OpenAI без ключа не виконано.

`scripts/smoke.ps1`: усі 14 перевірок пройшли. Перевірено запущений сервер: готовність моделі, HttpOnly-cookie, ізоляцію сесій, заборону пропуску, помилку знаменника, конфлікт ревізій, усі три вправи, підсумок, завантаження плану, Origin та видалення сесії.

## Візуальна перевірка

Перевірено завантаження сторінки та реакцію на помилковий знаменник у вбудованому браузері. Перевірено вузьке (390 px) та широке компонування, клавіатурне введення й повний навчальний маршрут до підсумку. Зображення `preview.png` показує фактичний інтерфейс, а не макет.

## Межі впевненості

Немає педагогічного пілоту, навантажувального тестування чи аудиту для публічного хостингу. Вільне пояснення в контрольній вправі перевіряється лише на наявність. Класифікатор може помилятися на запереченнях і незвичній лексиці. До використання реальними школярами потрібні додаткова валідація та правила обробки даних.
