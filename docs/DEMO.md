# Демонстрація сайту

1. Запусти `run.cmd`, відкрий http://127.0.0.1:5186.
2. Обери клас 5–9 і почни тренування.
3. Покажи помилковий знаменник, підказку, правильне зведення й суму.
4. Пройди другу вправу й третю самостійно, додавши пояснення.
5. Завантаж план повторення; обери інший клас.
6. Для 8–9 класів покажи від’ємні дроби. Смужки показують модуль із підписом знака.
7. OpenAI необов’язковий, вмикається прапорцем згоди після налаштування.
8. «Стерти сесію» очищає прогрес.
