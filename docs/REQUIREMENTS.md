# Відповідність завданню

Обрано один із запропонованих напрямів — **сократівський репетитор**. У PDF напрями є альтернативами, тому не потрібно реалізовувати всі чотири.

| Вимога | Реалізація / стан |
|---|---|
| Робочий прототип із ШІ | ASP.NET Core + браузерний інтерфейс, локальна ML-модель; необов’язковий API |
| Конкретна аудиторія | Учні 6 класу, які помиляються в додаванні дробів із різними знаменниками |
| Повний шлях користувача | Перша задача → адаптована практика → самостійна задача → план повторення |
| Допомога замість підміни | Навідні запитання, перевірка кожного кроку, відсутність довільного виводу моделі |
| Захист від помилок ШІ | Цілочисельна перевірка, дозволені категорії, фіксовані правила, резерв при збої API |
| Безпека й приватність | Мінімальна сесія у пам’яті, стирання, згода на API, пояснення переданих даних |
| Українська мова | Інтерфейс, підказки, приклади, промпт і документація українською |
| Код та історія Git | Git-історія відображає реальні етапи роботи; цільовий репозиторій: github.com/ro2bi/29092026_kompProject |
| README, моделі, промпти | README містить запуск, опис моделей, повний промпт, межі й тести |
| Ключі поза кодом | `.env.example`, `.gitignore`, змінні середовища на сервері |
| Демо | `docs/DEMO.md` із трихвилинним сценарієм та очікуваними діями |
| Команда 3–5 осіб, дедлайн | Організаційна частина: користувач має підтвердити склад та час подання; учасників не вигадано |

Живий виклик платного API потребує налаштувань користувача. Наявність локального режиму не означає, що зовнішній API вже перевірено.
