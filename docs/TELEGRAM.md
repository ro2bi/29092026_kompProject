# ДрібКрок — Telegram-бот для тренування дробів

Український навчальний прототип на C# / .NET 8. Учень обирає рівень 5–9 класу, розв’язує дві вправи покроково та третю самостійно. Бот перевіряє числа кодом, аналізує пояснення за допомогою ШІ та пропонує план повторення. Він не видає готовий розв’язок на прохання.

## Створення бота і запуск на Windows

1. У Telegram відкрий офіційного [@BotFather](https://t.me/BotFather). Перевір точне ім’я користувача.
2. Надішли `/newbot`, задай назву (наприклад, ДрібКрок) та унікальне ім’я користувача, яке закінчується на `bot`.
3. BotFather видасть токен. Не надсилай його в чат, не додавай у GitHub. Якщо розкрив токен — перевипусти через BotFather.
4. У папці проєкту скопіюй `.env.example` у `.env` (саме `.env`, не `.env.txt`). У рядку `TELEGRAM_BOT_TOKEN=` після `=` встав токен.
5. Потрібен .NET SDK 8 або 9. На комп’ютері розробки SDK уже встановлено. Запусти `run-telegram.cmd` і залиш вікно відкритим.
6. Відкрий свого бота за посиланням від BotFather і надішли `/start`. Обери клас кнопкою.

Або з термінала у корені проєкту:

```powershell
Copy-Item .env.example .env # лише якщо .env ще немає
notepad .env
dotnet run --project DribKrok.Telegram -c Release
```

Інтернет потрібен для Telegram навіть з локальною моделлю. Бот використовує long polling: сайт, домен, відкритий вхідний порт і окремий вебсервер не потрібні. Програма має працювати на комп’ютері або хостингу. Зупинка — Ctrl+C. Запускай одну копію на токен. Якщо вже налаштований webhook, застосунок повідомить про це і не змінюватиме його; найпростіше створити окремого бота.

## Навчання

Банк містить 40 вправ (по 8 на рівень), з яких випадково обираються три різні:

| Рівень | Зміст |
| --- | --- |
| 5 клас | Додатні дроби з однаковими знаменниками |
| 6 клас | Різні знаменники, прості спільні кратні |
| 7 клас | Складніші знаменники, суми понад одиницю |
| 8 клас | Додатні й від’ємні дроби |
| 9 клас | Складніші знакові дроби, скорочення та нульові суми |

Це приблизні рівні складності для повторення, не повна шкільна програма. Усі вправи стосуються додавання дробів.

Відповідай на поточне питання: знаменник → два чисельники через пробіл → сума. Пояснення додавай після `|`: `12 | шукаю спільне кратне` — приклад формату, не універсальна відповідь. У третій вправі одразу введи суму та пояснення від 10 символів. Довжина пояснення перевіряється, але його зміст не оцінюється як шкільна оцінка.

Команди: `/help`, `/level`, `/new`, `/current`, `/hint`, `/next`, `/progress`, `/privacy`, `/ai_on`, `/ai_off`, `/forget`. Кнопки старих кроків відхиляються; старі кнопки вибору класу можуть почати нове тренування. `/level` і `/new` показують меню; вибір класу замінює поточний прогрес.

## Як працює ШІ та API

За замовчуванням працює справжня локальна модель `drib-nb-2`: мультиноміальний наївний Байєс, символьні триграми, згладжування Лапласа, 60 коротких навчальних прикладів, 6 категорій. Категорії: додавання знаменників, незмінений чисельник, прохання готової відповіді, спільний знаменник, помилка знака, невпевненість. Оцінка впевненості не є каліброваною ймовірністю.

Для OpenAI заповни `OPENAI_API_KEY` та `OPENAI_MODEL` у `.env`. Обери доступну твоєму акаунту модель із підтримкою Responses API та Structured Outputs. У Telegram учень надсилає `/ai_on`, читає опис передачі даних і підтверджує згоду кнопкою. `/ai_off` вимикає передачу. Ключі не вводяться у Telegram.

`CoachClient.cs` надсилає лише пояснення до `POST https://api.openai.com/v1/responses`, з `store=false`, українською інструкцією `Prompt` та суворою JSON-схемою з дозволеними категоріями. ШІ повертає лише категорію; числа перевіряються цілими числами у `Lesson.cs`. Готові підказки обираються кодом. Відмова, неправильний JSON, помилка мережі або таймаут переводять запит на локальну модель.

Документація: [Telegram Bot API](https://core.telegram.org/bots/api), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

## Дані та обмеження

Бот працює лише у приватних чатах. ID чату, прогрес, прийняті числові кроки й згода зберігаються тільки в пам’яті, до 30 хвилин бездіяльності або перезапуску. Очищення виконується під час polling; при тривалому обриві мережі може затриматися. Немає бази учнів чи запису пояснень у файли. `/forget` видаляє стан цього учня, але не історію Telegram та не вже передані провайдеру дані. Telegram отримує повідомлення у будь-якому режимі. `store=false` не гарантує відсутності службового зберігання в OpenAI. Не надсилай персональні дані.

Прототип обробляє повідомлення послідовно, до 1000 активних сесій; це не сервіс для великої школи. Якщо відповідь не доставлена, надішли `/current`: крок міг бути вже перевірений. Після перезапуску прогрес скидається, а непрочитані оновлення Telegram можуть обробитися заново. Запит готової відповіді та довільні інструкції учня не можуть змінити математичну перевірку.

## Код і перевірка

- `DribKrok.Telegram`: polling, Telegram API, команди, кнопки й сесії.
- `DribKrok.Core`: банк вправ, математична перевірка, локальна модель й OpenAI-клієнт.
- `DribKrok.Tests`: автоматичні перевірки, HTTP-заглушки без токенів.
- `DribKrok.Telegram.sln`: основне рішення для бота.
- `DribKrok.Web` та `run-web.cmd`: попередній вебпрототип, окрема [інструкція](docs/WEB.md).

Запусти `test.cmd`. Результати й обмеження перевірки — [VALIDATION](docs/VALIDATION.md). [Демонстрація](docs/DEMO.md), [відповідність завданню](docs/REQUIREMENTS.md).
